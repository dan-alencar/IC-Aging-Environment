# minutes/ — Atas de reunião semanal

*[Read in English](README.md)*

O documento de plano exige (Seção 5.3) uma ata escrita e versionada para cada reunião
semanal de 60 minutos da equipe, com as decisões destacadas explicitamente, além da
ata que cada trilha de estudo da Fase 0 produz quando arguida. Use
`0000-template.md` como ponto de partida para cada uma; nomeie os arquivos como
`NNNN-AAAA-MM-DD-topico-curto.md` em ordem crescente, para que fiquem ordenados
cronologicamente (ex.: `0001-2026-03-02-kickoff.md`).

Atas não são burocracia opcional aqui — o Gate A e o Gate B (Seções 5.2–5.3 do plano)
são decididos pelo orientador com base na evidência disponível naquela semana, e as
atas fazem parte dessa trilha de evidência. Registre bloqueios conforme são
relatados, não como um resumo retroativo.
