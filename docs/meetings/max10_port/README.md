# minutes/ — Weekly meeting minutes

*[Leia em português](README.pt-BR.md)*

The plan document requires (Section 5.3) a written, versioned minute for every weekly
60-minute team meeting, with decisions explicitly highlighted, plus the ata each
Phase-0 study track produces when defended. Use `0000-template.md` as the starting
point for each one; name files `NNNN-YYYY-MM-DD-short-topic.md` in increasing order
so they sort chronologically (e.g. `0001-2026-03-02-kickoff.md`).

Minutes are not optional bookkeeping here — Gate A and Gate B (plan Sections 5.2–5.3)
are decided by the advisor on the evidence available at that week, and the minutes
are part of that evidence trail. Write down blockers as they're reported, not a
retroactive summary.
