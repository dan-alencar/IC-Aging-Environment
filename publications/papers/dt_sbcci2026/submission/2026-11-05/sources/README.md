# IEEE D&T Special Issue (SBCCI 2026 extension)

Extended version of the SBCCI 2026 paper "Quantifying the Effect of Burn-In Thermal Control on Delivered Acceleration Factor and On-Chip Slack-Sensor Fidelity in an FPGA Target" (`../gsem/`), invited to the IEEE Design & Test special issue.

- **Submission type:** "SI: SBCCI 2026". **Due 2026-11-23**; planned submission 2026-11-22.
- **16 nm (Artix US+) go/no-go:** 2026-11-15. A commented-out slot is in `manuscript/main.tex`; the paper compiles and reads complete without it.
- **Limits:** ≤ 5,000 words including references and bios (each figure/table counts 200), ≤ 12 references, title ≤ 9 words, abstract ~100 words. `make check` prints the count.

`HANDOFF.md` has the brief, ground rules and phases. The handoff's `dt/` paths map to this folder.

## One command

```bash
make          # raw CSVs -> analysis -> values.tex -> figures -> main.pdf -> budget + number audit
make analysis # Python only        make pdf   # LaTeX only        make check # budget + audit
```

The first `make` creates `.venv` (numpy, scipy, pandas, matplotlib). LaTeX needs only packages in TeX Live 2020; `siunitx` and `lettrine` were removed on purpose.

## Layout

| Path | What |
|---|---|
| `main.pdf` | Current manuscript (copied from `manuscript/build/`) |
| `manuscript/main.tex` | Source. Every result is a `\v…` macro from `generated/values.tex`. |
| `manuscript/figures/` | Generated by `analysis/make_figures.py` |
| `analysis/dtlib.py` | Loaders and estimators (cadence-aware; reproduces the TIP7266 estimators) |
| `analysis/run_analysis.py` | Per-campaign stress, noise, MI, hysteresis, detectability, controls → `generated/results_sensor.json` |
| `analysis/pid_bench.py` | FOPDT, SIMC, 100 °C oven tests → `generated/results_pid.json` |
| `analysis/wordcount.py`, `analysis/audit_numbers.py` (+ `number_whitelist.txt`) | D&T budget check; orphan-number audit |
| `INVENTORY.md` | Phase 0: raw data per campaign, CUT and device answers |
| `drafts/2026-11-04_contingency/` | Frozen snapshot of the draft received on 2026-11-04. Do not edit. |
| `generated/` | Script outputs only. Never hand-edit. |

## Data

The raw logs are versioned under `data/campaigns/` at the repo root; see its `README.md` and `SHA256SUMS`. `analysis/dtlib.py:CAMPAIGNS` maps each campaign key (`bb23`, `pid23`, `bb164`, `rca212`) to its file.
