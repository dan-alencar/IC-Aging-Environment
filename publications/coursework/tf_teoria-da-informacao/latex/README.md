# LaTeX source tree — Final Project (TF), Teoria da Informação TIP7266

Final-document scaffold for the project described in the `../0*.md` planning files.

## Build

```bash
cd latex
latexmk -pdf main.tex          # preferred
# or:
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

`main.tex` uses `article` for portability. To switch to IEEE format, change the
`\documentclass` line to `\documentclass[conference]{IEEEtran}` (see the comment
block at the top of `main.tex`).

## Workflow contract

Numbers and figures are **never typed into prose**. The analysis scripts emit:

- scalars → `generated/values.tex` (one `\newcommand` each; `[TODO]` marks pending);
- tables → `tables/*.tex`;
- plots → `figures/*.pdf`.

Prose in `sections/` references them via macros (`\valHs`, `\valRsqLinear`, …),
so re-running the analysis regenerates the paper with zero transcription error.
Values already filled from `Tentative_1_20260524_203756.csv` are the dataset and
second-order statistics; `[TODO]` macros await the Tier-1 information analyses
listed in `../05_Execution_Plan.md`.
