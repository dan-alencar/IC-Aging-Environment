# Publications & Academic Materials

This directory stores research papers, theses, coursework deliverables, and reference literature produced or used by the research group.

## Directory Structure

```
publications/
├── papers/
│   └── gsem/              # Research papers submitted/published by the GSEM group (SBCCI, JICS, IEEE)
├── theses/
│   └── tcc/               # Undergraduate theses (TCC), dissertations, and related literature
├── coursework/
│   └── teoria_da_informacao/ # Information Theory graduate project and report
└── literature/
    ├── refs_sbcci_2025/   # Categorized reference literature for SBCCI publications
    └── references.bib     # Group BibTeX database
```

## References Management
To avoid Git repository bloat, group members should prioritize tracking BibTeX entries in `references.bib` or using the group's Zotero shared library rather than committing large batches of commercial PDFs.
