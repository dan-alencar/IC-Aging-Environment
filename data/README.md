# Experimental Data & Campaign Guidelines

This directory defines the standards for logging, storing, and sharing experimental data generated by the IC-Aging research group.

## Data Storage Policy

1. **Git Policy:**
   - Raw multi-day campaign CSV files (`> 1 MB`) **MUST NOT** be committed to Git.
   - The directory `data/campaigns/` is locally preserved on disk but globally ignored by `.gitignore`.
   - Small verification logs (`< 1 MB`) used for offline testing or plot validation are kept under `data/sample_logs/` and are tracked by Git.

2. **Long-Term Data Archival:**
   - Completed campaign datasets for published papers should be archived with a permanent DOI on **Zenodo** or stored on the lab's shared storage NAS.

## Standardized Campaign Header Specification
